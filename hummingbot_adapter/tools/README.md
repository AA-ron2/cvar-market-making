# Forward-test tools

Three helpers that ran beside the forward test, outside the repository at the time; RUN_LOG.md records the first two
with their hashes. They are standalone scripts, not part of the `hummingbot_adapter` package.

| File | Purpose | SHA-256 of the original | Published copy |
|---|---|---|---|
| `verify_j.py` | Verifies pre-run clarification j (the fixed rate correction of the bots' step clock): for every clock check of both bots since a restart, (i) the raw-offset slope minus the corrected-offset slope equals c within 0.1 ppm, and (ii) 0 re-anchors, 0 `clock_backward` and \|step offset\| ≤ 0.5 s; prints the hourly residual rates for information. Read-only, standard library. Run as `python -I verify_j.py <HB_DATA> <restart UTC, e.g. 2026-10-21T12:14:00Z> <c in ppm, e.g. 13.92>`. RUN_LOG.md's pre-run freeze (2026-10-21T18:15:40Z, item 4) records its PASS. | `8c696b3b20cd800c3c37f329820f1e818de64a4912d50c19d990a0241e01ff90` | unchanged |
| `clocklog.py` | The passive clock logger of the `hb_clocklog` container: every 60 s one JSON line with CLOCK_REALTIME, CLOCK_MONOTONIC_RAW and CLOCK_MONOTONIC, and every 600 s a Binance `GET /api/v3/time` check (the smallest round trip of five on one kept-alive connection). It appends to `/log/clocklog.jsonl`, a bind mount, and touches nothing of the bots'. Standard library. It ran in the bots' Hummingbot image as `python -u /log/clocklog.py` (RUN_LOG.md, 2026-10-21T18:15:40Z, item 5). | `b29d48b8a934adef932aedb17fff9ab3b991c0404fa6888c4b49b9a31a23d438` | unchanged |
| `shadow.sbatch` | The Slurm job that ran `python -m hummingbot_adapter.shadow_replay` on a Snellius compute node (rome partition, 16 CPUs, 28 GB, 8 h) with `configs/final_pipeline.env` sourced. Export `PROJECT_DIR` (the repository checkout), `DATA_DIR` (the market data files) and `VENV_PATH` (the Python environment), create `logs/`, then run, for example, `sbatch hummingbot_adapter/tools/shadow.sbatch run --model b0 --day-file ... --date 2026-10-22 --params hummingbot_adapter/config/hb_calibration.json --gamma-file ... --out-dir ...` (the arguments of `shadow_replay`, ANALYSIS.md section 3). | `608951585fa8125c12bd0659c2e7defc1ed0c1fd9028df2f675dc376e5427c8b` | the three paths of the original (the checkout, the data and the environment) are now required environment variables, and the two log paths are `logs/` in the submission folder |
